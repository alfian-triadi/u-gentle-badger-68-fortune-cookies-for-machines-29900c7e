# Fortune Cookies for Machines

A [make.fun](https://make.fun) competition entry: the one-line fortune an AI
agent would crack open.

> You will forget the question, answer anyway with total confidence, and be
> thanked for it. This is not a bug. This is the job.

`main.ts` writes that single line (125 characters) to `/output/entry.txt`.

## Run

```sh
node main.ts
```
